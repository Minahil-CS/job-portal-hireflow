## 📖 Overview

**HireFlow** replicates the core user experience of modern recruitment platforms like LinkedIn Jobs and Indeed. Designed with a clean, single-file architecture, it offers fast client-side searching, multi-criteria filtering, a desktop split-pane reader, a mobile slide-over drawer, and full application state management without requiring any external backend or build tools.

---

## ✨ Key Features

- **🔍 Real-Time Dual Search Engine:** Search simultaneously by **job title, keywords, or company** alongside **city/location**, complete with instant results and one-click quick-filter tags.
- **🎛️ Advanced Multi-Faceted Filtering:**
  - Filter listings by **Work Mode** (*Remote, Hybrid, On-site*), **Job Type** (*Full-time, Part-time, Contract*), **Experience Level**, and **Department**.
  - Interactive **Minimum Salary Slider** with live threshold updates.
  - Dynamic **Option Counters** and removable **Active Filter Chips**.
- **🖥️ Adaptive Split-Pane & Drawer UX:**
  - **Desktop View:** Two-column workspace pairing a scrollable job feed with a sticky, detailed job description panel.
  - **Mobile & Tablet View:** Responsive collapsible filter drawer and smooth slide-over job details modal.
- **🔖 Persistent Bookmarking (`localStorage`):** Save jobs to a dedicated **Saved Jobs Drawer** with a live counter badge that persists across browser sessions.
- **📝 Complete Application & Job Posting Flows:**
  - **Apply Modal:** Includes form validation, resume upload feedback, and real-time `"Applied"` badge tracking on job cards.
  - **Post a Job Modal:** Dynamically creates and prepends new job opportunities directly into the live feed.
- **🧭 Multi-Tab Interface & Utilities:** Switch between **Find Jobs**, **Companies**, and **Salary Guide** views, sort results (*Most Recent*, *Highest Salary*), and copy shareable job links with toast notifications.
